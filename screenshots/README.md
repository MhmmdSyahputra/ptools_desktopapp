# Screenshots

Tambahkan screenshot aplikasi Anda di folder ini.

## Screenshot yang Direkomendasikan:

1. **main-scan.png** - Interface utama dengan hasil scan
   - Tampilkan hasil scan dengan beberapa project
   - Highlight fitur utama (summary, kategori, project list)
   - Ukuran: 1600x1000px atau lebih besar

2. **empty-state.png** (opsional) - State ketika tidak ada junk folder
   
3. **scanning.png** (opsional) - Progress saat scanning

4. **delete-confirm.png** (opsional) - Dialog konfirmasi delete

## Tips Screenshot:

- Gunakan resolusi tinggi (minimal 1600px width)
- Tampilkan data yang realistis
- Windows: Gunakan Snipping Tool atau Win + Shift + S
- macOS: Gunakan Cmd + Shift + 4
- Linux: Gunakan Spectacle atau GNOME Screenshot

## Format File:

- Format: PNG (untuk kualitas terbaik)
- Nama file: lowercase dengan dash (contoh: main-scan.png)
- Compress jika file terlalu besar (gunakan TinyPNG atau sejenisnya)

Setelah menambahkan screenshot, pastikan untuk commit ke repository:

```bash
git add screenshots/
git commit -m "Add application screenshots"
git push
```
